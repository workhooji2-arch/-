# 조교 급여 대장

조교 등록(가입), 근무 기록, 시급 기반 급여 계산을 관리하는 웹앱입니다. 관리자 계정과 조교 계정이 분리되어 있으며, 조교는 가입 후 자신의 근무 기록과 급여만 볼 수 있고, 관리자는 모든 조교의 기록을 보고 관리할 수 있습니다.

- 로그인 / 조교 회원가입 (비밀번호는 bcrypt로 해시되어 저장됩니다)
- 조교: 출퇴근 타이머, 근무 기록 직접 입력, 급여 명세서(3.3% 원천징수 자동 계산) 확인
- 관리자: 조교별 시급 설정, 모든 조교의 근무 기록 관리, 월별 전체 급여 요약

## 기술 스택

Next.js (App Router) · PostgreSQL · Prisma · 쿠키 기반 JWT 세션 인증

이 프로젝트는 서버와 데이터베이스가 있는 실제 웹앱이므로, 조교마다 각자의 기기(휴대폰/노트북)에서 접속해도 모든 데이터가 한 곳(데이터베이스)에 모입니다.

## 처음 배포하기 (Vercel + Neon 추천)

무료로 시작할 수 있는 조합입니다. 아래 순서대로 진행하세요.

### 1. 데이터베이스 만들기 (Neon)

1. [neon.com](https://neon.com)에서 무료 계정을 만들고 새 프로젝트를 생성합니다.
2. 생성된 연결 문자열(Connection string)을 복사해둡니다. `postgresql://...` 형태입니다.

### 2. Vercel에 배포하기

1. 이 GitHub 저장소를 [vercel.com](https://vercel.com)에서 Import 합니다.
2. 프로젝트 설정의 **Environment Variables**에 아래 값을 추가합니다.

   | 이름 | 값 |
   |---|---|
   | `DATABASE_URL` | 1단계에서 복사한 Neon 연결 문자열 |
   | `JWT_SECRET` | 임의의 긴 무작위 문자열 (예: `openssl rand -hex 32`로 생성) |
   | `ADMIN_USERNAME` | 관리자 아이디 |
   | `ADMIN_PASSWORD` | 관리자 비밀번호 (배포 후 계정 생성에만 사용, 안전하게 보관하세요) |

3. Deploy를 눌러 배포합니다.

### 3. 데이터베이스 테이블 생성 + 관리자 계정 생성

따로 하실 일이 없습니다.

- **테이블 생성**: 배포할 때 `prisma migrate deploy`가 실행되어, 아직 적용되지 않은 테이블 변경만 적용합니다. 이미 만들어진 테이블과 기존 데이터는 그대로 유지됩니다.
- **관리자 계정**: 로그인 시도가 들어올 때 `ADMIN_USERNAME` 계정이 없으면 만들고, 이미 있으면 `ADMIN_PASSWORD` 값과 다를 때만 비밀번호를 갱신합니다.

관리자 계정을 빌드가 아니라 실행 시점에 만드는 이유는, 빌드 환경에 관리자 환경 변수가 전달되지 않는 경우가 있기 때문입니다. 이렇게 두면 그런 경우에도 배포가 실패하지 않습니다.

관리자 비밀번호를 바꾸고 싶으면 Vercel에서 `ADMIN_PASSWORD` 값을 수정하고 재배포하면 됩니다.

배포가 끝나면 배포된 주소(예: `https://your-app.vercel.app`)에서 관리자 아이디/비밀번호로 바로 로그인할 수 있습니다.

### 4. 조교에게 공유하기

`https://your-app.vercel.app/signup` 링크를 조교들에게 공유하세요. 각자 가입하면 관리자 화면의 "조교 관리" 탭에 나타나고, 시급을 설정해주면 그때부터 근무 기록을 시작할 수 있습니다.

## 로컬에서 개발하기

운영 데이터가 섞이지 않도록, Neon에 개발용 브랜치/프로젝트를 하나 더 만들어 `DATABASE_URL`로 연결하는 것을 추천합니다.

```bash
npm install
npm run db:deploy   # 테이블 생성
npm run db:seed     # 관리자 계정 생성
npm run dev
```

## 참고

- 시급을 나중에 수정해도 이미 기록된 근무 건의 금액(및 원천징수·실수령액 계산)은 바뀌지 않습니다. 기록 시점의 시급이 함께 저장되기 때문입니다.
- 원천징수는 3.3% 고정입니다(사업소득 원천징수 관행 기준). 실수령액 = 총 지급액 − 원천징수액입니다.
- 세션은 httpOnly 쿠키에 저장된 JWT로 관리되며, 비밀번호는 절대 평문으로 저장되지 않습니다.
